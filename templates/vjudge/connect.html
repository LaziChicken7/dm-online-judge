Hướng dẫn lấy cookie JSESSIONID từ trình duyệt (chính xác 100%):

⚠️ Lưu ý quan trọng: Cookie JSESSIONID là loại bảo mật (HttpOnly) nên không thể lấy bằng lệnh JavaScript Console (document.cookie). Hãy làm theo 1 trong 2 cách sau:
👉 Cách 1 (Đơn giản nhất qua thẻ Application / Storage):
  1. Đăng nhập tài khoản của bạn tại https://vjudge.net trên trình duyệt.
  2. Bấm phím F12 (hoặc nhấp chuột phải chọn Kiểm tra / Inspect).
  3. Chọn thẻ Application (trên Chrome, Edge, Cốc Cốc) hoặc thẻ Storage (trên Firefox).
  4. Ở danh mục bên trái: mở mục Cookies → chọn https://vjudge.net.
  5. Tại bảng danh sách bên phải: tìm dòng có tên JSESSIONID → nhấp đúp vào cột Value để copy giá trị (ví dụ: 3341751E143840100C1737BB3ACBA1DA).
  6. Dán giá trị đó vào ô bên dưới rồi bấm Lưu Cookie & Kết nối ngay.
👉 Cách 2 (Lấy từ thẻ Network / Mạng):
  1. Trên trang vjudge.net, mở F12 → chọn thẻ Network → bấm F5 tải lại trang.
  2. Bấm vào dòng request đầu tiên (tên vjudge.net) → chọn thẻ Headers → kéo xuống phần Request Headers.
  3. Copy toàn bộ giá trị sau chữ Cookie: và dán vào ô bên dưới.
