int main(int argc, char* argv[]) {

}

Cách hoạt động tương tự Codeforces Polygon:

  1. Ở mục Data zip file ngay bên trên: Bạn chỉ cần tải file ZIP chứa các file input (ví dụ: 1.inp, 2.inp,... hoặc test01/APLUSB.INP).
