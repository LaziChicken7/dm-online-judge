1. Cấu hình: Đặt file checker.cpp vào thư mục / file zip dữ liệu bài tập. Thư viện testlib.h đã được tích hợp sẵn trên hệ thống chấm.

2. Mẫu mã nguồn checker.cpp:

#include "testlib.h"

int main(int argc, char* argv[]) {
    registerTestlibCmd(argc, argv);
    int ja = ans.readInt();
    int pa = ouf.readInt();
    if (ja != pa)
        quitf(_wa, "Sai kết quả: dự kiến %d, nhận được %d", ja, pa);
    quitf(_ok, "Kết quả chính xác!");
}

Các luồng chuẩn: inf (dữ liệu vào), ouf (bài làm nộp), ans (đáp án chuẩn).
